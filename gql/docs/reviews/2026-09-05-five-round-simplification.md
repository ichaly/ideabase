## 行为与兼容性

保留 SQL 编译路径、内置多租户、权限检查、审计、事务提交后发布、实例组合、多副本撤权和重放校验，以及统一 `/graphql` 查询/突变/SSE 订阅入口。
关系 connect/disconnect 仍按原顺序执行，并保留各自 SQL 限定方式、租户作用域和更新策略检查。
中间表可能先预留列再填写参数；列去重必须检查列切片，不能仅检查值映射。新增回归测试覆盖此约束。

删除的公开 Go 符号需要调用方迁移；详见 MIGRATION.md。GraphQL 与配置键不变，不能把执行行为保持不变理解为所有 Go API 源码兼容。

## 验证

- 每轮均通过核心包、compiler、metadata、protocol、transport、internal、database 测试，以及 `go vet ./...` 和 `git diff --check`。
- 最终完整竞态测试：`go test -race . ./transport ./compiler/pgsql` 通过。
- 使用独立 PostgreSQL 16 容器加载 examples/schema.sql，`go test ./examples` 通过；验证后已删除容器。
