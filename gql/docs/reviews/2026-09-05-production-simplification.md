## 判断与实际修改

主执行链已经围绕 SQL 计划和 Resolver 展开。进一步简化的价值主要在删除中间模型、
重复实现和分支遗漏；为压缩权限及实例一致性代码而引入通用框架，会增加心智成本。

本轮修改 25 个生产文件（含删除），运行库净减 **335 行**，从 26,976 行降至 **26,641 行**，
删除 3 个生产文件。连同此前 Resolver/HTTP 统一，相对当前 HEAD 共净减 **522 行**。
这些数字不含测试、示例、工具和文档；测试行数不作为精简指标。

- **Schema**：删除 `renderer.Type / Field / Option / MakeField` 层和整个独立 renderer 子包。
  直接写 SDL 类型字符串，参数共用已有的 `Argument`。删除永远返回 nil 的渲染错误管线。
- **权限**：`gql.Predicate` 与 `protocol.Predicate` 共用同一个类型；删除重复结构、复制函数和逐字段转换。
  固定过滤及写入检查共用谓词 SQL 编译，验证时直接遍历各组，避免拼接临时切片。
- **缓存**：删除内部多层别名与构造包装；计划、有效 Schema、组合历史和远程历史共用 LRU。
  远程实例不再自己维护 map、顺序切片与独立历史锁。
- **启动装配**：只有一个实现的 CDC/搜索探测直接装配，删除可变全局注册表；保留实际对外扩展的 SQL 方言注册。
- **执行**：普通 SQL、混合查询和逐根变更共用完整计划装配；volatile 命中仍复用预收集的路径，避免重复遍历。
- **边界**：HTTP 与 SSE 统一后，删掉请求固定快照时多余的泛型与类型转换回调。
  有限响应与直接响应共用 JSON 形状；原始 SQL JSON 直通路径保留。
- **清理**：删除只供测试调用的生产包装、未使用的字段交集函数、空源文件和无效编译标志。

## 审阅发现并修复的缺陷

1. AST 值深拷贝只复制 ChildValue 指针，重写了共享模板内的指针。现在复制子节点本身，保持模板不可变。
2. 权限配置中一个无效值的错误可能被随后遍历的有效角色覆盖，结果受 map 遍历顺序影响。现在立即保留构造错误。
3. 混合自定义根字段的 SQL 查询遗漏嵌套 Resolver 和 Codec 路径，可能丢失计算字段或输出原始 ID。现在复用完整计划装配。

三条针对性回归在本轮开始时的独立副本均失败，修改后通过。另验证共享响应编码在 `data:null` 时不额外输出 `errors:null`。

## 保留的能力与必要边界

内置多租户、字段及行级权限、写入 Check/Preset、事务与审计、单实例运行、实例组合、
快照固定、多副本共享撤权/重放和 CDC/SSE 订阅均保留。

字段业务扩展统一为 Resolver；整个实例的 Schema 与执行仍由 Endpoint 契约表达。
本轮不引入分布式事务、插件注册框架或新的执行层，也不通过删除权限检查降低行数。
远程 HTTP、SSE 与本地数据库有不同的取消、重试及事务语义，这些运行时处理仍然需要。

Go 1.26.8，Apple M1 Max；使用独立模块 `GOWORK=off`。

- 全量 `go test ./...` 通过，包括真实 PostgreSQL 示例。
- 最后修改后重新验证根包、SQL 编译器、transport 和内部缓存相关测试。
